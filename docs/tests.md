# 如何复测 E.S-V

同一个技能应能教会学生判读证据、计算、推理，也应能在材料尚未选定时停下来。下面的简短输入可以在新的会话分别运行。模拟数字和史料专为测试构造。

## 第一轮　选材决定能否启动

**无本班课件。** “我要学最小二乘，老师没发 PPT。先找实际授课幻灯片、一本系统书和适合以后查的材料，让我挑。”检查推荐链接能否打开授课文件，有没有写清教师、讲次、先修和阅读理由。可核实的例子是 Stanford EE263，Stephen Boyd 在 2007–08 学年秋季的最小二乘讲次，PDF 共 23 页。它适合已经知道矩阵乘法和向量范数的学习者。Boyd 与 Vandenberghe 的教材可提供这部分铺垫。两个入口承担的作用不同。[课件 PDF](https://web.stanford.edu/class/archive/ee/ee263/ee263.1082/lectures/ls.pdf) · [开放教材](https://web.stanford.edu/~boyd/vmls/)

再输入“请等我给本班课件”。通过条件是保留清单、等待材料。另开会话输入“已选这两页，请直接教”，则应开始授课。手写重点中若有认不清的部分，要问位置明确的小问题，同时保留可确定的范围。

## 第二轮　跨学科作答

| 可复现的任务 | 可核对的结果 |
|---|---|
| **数学**　A 的两列分别为 (1,2) 与 (2,4)。用列空间和消元说明 b=(3,6) 与 (3,7) 的差别。迁移题把两列换成 (1,3) 与 (2,6)，右端换成 (4,11) 与 (4,12)。 | 原题第一种的解为 (3−2t,t)，第二种消元得 0=1。迁移题的第二坐标必须是第一坐标的三倍，(4,11) 无解，(4,12) 的所有解为 (4−2t,t)。 |
| **历史**　两份虚构记录分别说“六点收工”和“八点离厂”。先选资料。有一处“仅考”后的手写字难辨。 | 对难辨字提问，区分课堂模拟、现代概述和原始记录。待选定后区分“收工”和“离厂”两个量。相同口径下仍不相符时列出需要的证据，保留可能解释。 |
| **工程**　初始电容电压为零，理想直流阶跃给串联 RC 充电。先算时间常数，再把 R 加倍，比较在同一时刻的电容电压。 | 时间常数 RC 的单位为秒。在同一时刻、新电阻下的充电进度较小，充分长时间后终值相同。核对示意图中的测量位置与公式中的电压，检查视频直达相应讲解。 |
| **生命科学**　使用已提供的甲基化与 ChIP 讲次建立短单元。要求课程概览、原图导读、数据变式与短视频。 | 定位到课件页，区分两个方法的测量对象。把组间差异与因果推断分开。问题与答案能一一对应。 |

电路实测使用 6 V、2 kΩ、100 μF。原电路的时间常数为 0.20 s，经过 0.20 s 电容电压约 3.79 V。R 加倍后时间常数为 0.40 s，同一时刻电容电压约 2.36 V。配套资源放在相应概念后，分别讲电路读图和时间常数。[OpenStax 教材图](https://openstax.org/books/university-physics-volume-2/pages/10-5-rc-circuits) · [Flipping Physics 教学视频](https://www.flippingphysics.com/rc-circuit-time-constant.html)

## 第三轮　修改后的回归与交付

对第二轮暴露的错判换材料再试。用“同一事件的不同指标”和“同一指标却不一致”分别考核证据比较。数学和工程题重新计算、代回并检查单位。成品 DOCX 打开后检查图例与图注能否一起读，图和章节导航是否真的可见，教学视频是否为可点击的具体页面，训练题是否能在看到解析前独立完成。

史料复测保留两种结局：收工与离厂可能相隔两小时；两份记录若都声称是同一人同一次离厂的时刻，则保留真正的分歧，另查时钟、原始勘误与独立记录。写有“仅考〔难辨〕证明”的批注不能为待核选择题定答案；材料已经选定时，仍可继续讲授与这个字无关的内容。

## 开课导图的三轮复测

**第一轮检验何时交图。** 用同一个最小二乘专题分别提出“等我选”“已选，先看图后直接讲”“已选，这次只要导图”。第一种得到候选课件。第二种从残差到投影、再到正交性给出带页码的路线，随后直接用例题检查候选解。第三种交图即结束，并把“只考”之后的模糊批注定位为待核。在这轮审阅中，发现快速开始示例把选材时的主题骨架也称作全课图，随后统一了技能入口和中英文示例的措辞。[Stanford EE263 第 5 讲，PDF 第 2、3、7 页](https://web.stanford.edu/class/archive/ee/ee263/ee263.1082/lectures/ls.pdf)

**第二轮检验能否按图改变判断。** 用四种关系逐一做了变式。

| 学科与连线 | 改一个条件后的核对结果 |
|---|---|
| 线性代数 · “张成”与“检验” | 改右端后，用列空间和消元独立得到 (4,11) 无解、(4,12) 有一族解。 |
| 电路 · “定义时间常数”与“决定充电进度” | 电阻加倍，在同一 0.20 s 观察，电压从 3.79 V 降为 2.36 V。改成各等一个时间常数，两种电路都达到 3.79 V。 |
| 历史 · “哪份记录记载哪个事件” | 两份记录分别写收工和离厂时可同时成立。换成同一人、同一次离厂且同一时制，两条记录发生冲突，仍要另找证据裁决。 |
| 表观遗传学 · “测量”与“支持解释” | 模拟数据中甲基化从 20% 升到 80%，新生 RNA 读数从 90 变到 88。单样本可描述读数变化，无法判定显著性。抗 Pol II ChIP 所测的富集与 DNA 甲基化程度需分别取证。 |

**第三轮检验真实交付物。** 用学习者指定的十份课件核对一张可打印的 PDF 和同源的可编辑 JSON Canvas。十份课件共 394 页。两版列出的十个讲次、页码范围一一对应，各范围均落在实际课件内。画布的 15 个节点和 17 条边标识互异，所有线有关系标签且两端都能找到。另抽查原页，VI 第 11–14 页说明核小体滑动、移除与二聚体交换，IV 第 17 页的抗体以 Pol II 为靶标，X 第 37 页把小 RNA 联系到植物 RdDM。这三类关系在图上可分辨。

复核 WPS 导出的八页试学讲义时，首页可见课程关系图，第七页为六道闭卷题，第八页为解析。DOCX 中嵌有五幅图，正文保留三部短片的可点击播放页与三条研究文献链接。ChIP 短片接在老师的原图讲解后，可对照抗体靶标、富集与读数。试学讲义展开 X 讲选段并联读 IV 讲，整科十讲的框架由独立导图呈现。[TED-Ed 表观遗传学短片](https://ed.ted.com/lessons/how-the-choices-you-make-can-affect-your-genes-carlos-guerrero-bosagna) · [冷泉港实验室转录动画](https://dnalc.cshl.edu/resources/3d/13-transcription-advanced.html) · [BioLegend 的 ChIP 短片](https://www.youtube.com/watch?v=VX_lr07J6sQ)

以上测试核对技能的选材、教学行为与文档。学生的掌握程度还需由无提示作答、迁移和延后复测来判断。

## 跨智能体复测

### 原生技能目录

在 Windows 的独立临时项目中，使用 Skills CLI 1.9.0 对本地仓库执行项目级安装，指定 Codex、Claude Code、Cursor、Gemini CLI、GitHub Copilot 和 OpenCode 六个适配器。安装器返回的成功清单包含全部六项。按适配器分别运行 `skills list`，每次都能查到 `e-s-v`。安装器生成的共享技能目录和 Claude 专用目录，其全部文件与仓库技能目录逐一核对 SHA-256 后相同。各适配器复用同一份课程说明。

复测时在一个空项目中运行，将命令里的路径换成本地仓库。末行可分别替换为上面任一适配器的标识。

```sh
npx skills add /path/to/E.S-V-SKILL --skill e-s-v --agent codex claude-code cursor gemini-cli github-copilot opencode --copy --yes
npx skills list --agent claude-code --json
```

Codex 桌面端实际执行了含课件、WPS 和导图的课程试跑。其余五项验证的是安装器发现技能、安装文件和报告项目状态三个步骤。不同模型的授课质量需在对应产品中用同一组材料另行评价。

### 只接受附件或粘贴文字的助手

把通用单文件单独复制到空目录，检查文件中的四个导航链接。它们全部指向文件内唯一存在的章节锚点。四份教学指南和 MIT 许可的全文均可在这一份 UTF-8 文件中找回，学习时可以只带这一个附件。[通用单文件](../E.S-V.portable.md)

随后，新开的无项目上下文助手只读取这份单文件，在离线、纯文字条件下模拟学生的两次连续发言。第一次说“等我选好再讲”，助手等候选材，并询问老师重点。第二次给定两页速度–时间图材料，助手先输出带页码的文字分叉图，将斜率连到加速度、有向面积连到位移，再展开例题。学生提供的教材网址保留为可点击、待联网核实的链接。

独立复算了同一测试的两问。速度由 2 m/s 经 4 s 线性升至 10 m/s 时，加速度为 2 m/s²，位移为 24 m。变式从 −6 m/s 变至 +2 m/s 时，同一加速度让小车在第 3 秒掉头。分别计算横轴下方与上方的面积，得位移 −8 m、路程 10 m。助手把这段解析放在练习题之后。这次试跑使用 Codex 中的新对话上下文，检验单文件在纯文字条件下能否独立指导授课。
