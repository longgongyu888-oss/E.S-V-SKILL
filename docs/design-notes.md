# E.S-V SKILL 的教学设计与参考来源

这项技能始于一次分子生物学课程复习。学习者第一次接触这门课，希望在有限时间内看懂老师的课件，读一份可以独立学习的讲义，再用练习找出薄弱处。最能说明需求的是一张复制叉图。学生可能记得“前导链连续、滞后链不连续”，遇到方向相反的图，仍会把新链的箭头画反。这时，教师需要指出复制叉整体移动的方向，示范怎样沿一段新链找到它的生长端，然后换一幅朝向不同的图让学生自己判断。这个做法同样适用于力学受力图、统计分布图和历史事件的因果图。

## 从课程材料到学生可以独立作答

| 当时遇到的教学问题 | E.S-V 的处理方式 |
| --- | --- |
| 一句“掌握 DNA 复制”遮住了老师在图上讲的方向、引物和实验依据 | 按课件页码拆出可检查的知识点，图、表、例题也纳入登记。将讲义中的解释或练习映射回原页。扫描模糊或读不清的地方单独标明。 |
| 带着零基础查阅几本教材，容易在术语之间来回翻 | 用主教材补定义和因果，用辅助教材解决具体疑点。在章首提出一个可回答的问题，从所需前提讲到一个完整例子，并指出它与后一章的关系。 |
| 选好了资料，打开第一讲却不知道要带着什么问题读 | 开课前给出全课程导图。学生从中心问题出发，能指出下一步先学什么、学到什么程度，以及讲义和课件中的对应位置。 |
| 两个来源看起来互相矛盾 | 先核对原页、图例、坐标方向和使用条件。确认有误时写清原位置、修正和依据，证据不足时保留疑点。 |
| 看懂了示意图，合上书却画不出关键关系 | 优先选标注清楚、来源可追溯的成熟原图，配上读图顺序和一道遮住标签也能做的题。难以用静态图表达的运动过程才补短片，在相应段落给出网页、时长、语言和观察目标。 |
| 临考时间很短，同时又担心落下细节 | 给出优先学习路线，保留可按章节或页码查找的细节。将例题拆作示范，在后面安排闭卷检索和换情境的题目，让作答结果决定下一轮复习。 |
| 导出后图注翻页，答案露在题目旁边 | 对要求的交付格式做实际阅读检查。WPS 讲义重点核对图与讲解能否同屏或同页、方向符号是否清楚、视频链接能否打开、作答前能否遮住解析。 |

这些选择也沿用了三种工作方法。`find-skills` 提醒我们先发现候选项目，再回到原仓库核实具体能力。`stop-that-shit` 提醒我们把精力花在与本次任务相称的交付上，单个概念的答疑可以在对话中完成。文档制作流程带来的经验是，文件生成后还要用阅读者将使用的方式打开，看看章节、图、题目与链接是否真的可用。

## 从一张图进入一堂课

例如，开课时学生面对“同一 DNA 序列怎样呈现不同的表达状态”这个问题。借鉴 Markmap 的层级设计，先看全科有哪些解释，再选择染色质这条分支。沿标有先修关系的连线，先认识核小体结构，才去解释结构改变如何影响 DNA 的可及性。想做研究笔记的学生可以在 Canvas 里补上课件页和自己读错的一幅图。上完这段后，学习者面对一幅新图，先独立判断并说出理由。教师依据答案给提示，安排回访，再用课件原页复核讲义有没有遗漏。七个项目的做法因而贯穿选定资料后的导学、授课、练习、复习与审查。
