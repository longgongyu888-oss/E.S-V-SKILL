# 把课件画成能用来学习的图

学生看完第一张图，应能指出“我从哪里开始”“下一章为什么接在这里”“学到什么程度可以往下走”。先选定资料，再画全课图。老师随后补充范围时，保留有效节点，改动受影响的来源、路线和自测。

## 从选定材料得到节点

1. 顺着实际讲次、章次浏览标题、关键图表、结论、练习和老师标记。为每个主题记下一个学生会问的问题、一个定位（讲次＋页或章＋节）、一个能当场观察的学习动作。写“根据坐标读出半衰期”“用两份史料比较事件发生时间”，比“理解动力学”“掌握史料”更容易自测。
2. 找能统领各章的中心问题，把回答这个问题必须解决的几件事设为主枝。密集细节移至章图或逐页伴读，保留原页入口。把原材料中每讲对回一个节点，若两讲被合并，要能找回各自承担的任务。若只选了一小节，在图上注明这张图覆盖到哪里。
3. 给每条跨枝连线写一句能读通的话，如“列空间**用于判定**方程是否有解”“档案 A 与 B **对照同一指标**”。课次先后、知识先修、测量关系和因果机制分别表述。需要因果箭头时，先核对材料是否支持方向、对象和成立条件。
4. 标明学习起点。教师明示重点附原页或口述来源，编者建议先学的分支写作“建议路线”。待核的手写处用位置指回原图。应试时间紧时可在全图标出首轮路线，再把暂缓的分支接到下一轮。

## 选对图形和交付格式

| 学习者此刻要做什么 | 适用图形 | 图上保留什么 |
|---|---|---|
| 第一次看全科结构 | 以问题为根的层级脑图；屏幕上可折叠，纸上分为总图和章图 | 主枝是子问题，叶节点有来源和自测。展开一枝仍能找到它在全科的位置。 |
| 解释跨章先修、推理或证据链 | 带关系词的概念图或流程图 | 以“需要”“测量”“比较”“在……条件下导致”等词连点；说明观察结果能支持哪些结论。 |
| 细读已有机制、波形、通路或历史地图 | 使用选定资料中清晰的专业原图或权威图源 | 在相关课文后标明图号、起读点和判断任务。总览图上的节点指向该处。 |
| 后续要自己整理、加错题或改连线 | 可编辑画布，例如 JSON Canvas；同步给可直接查看的图 | 复用同一组节点、来源和关系。学生可以在相应节点补写自己的解释或错题。 |

按宿主能力选渲染方式。Markdown 层级适合生成 Markmap 一类的折叠视图，Mermaid 的带标签连线适合跨章关系；文件交付可用 PDF 或在 WPS 讲义内嵌高清图。已能显示静态图时即可上课。使用 JSON Canvas 时，节点与线各有唯一标识，线的两端都能定位到已有节点，修改后重新检查。单独保存结构文本时，同时提供能直接看到的图。

## 交给学生之前

- 按学习者实际打开文件的方式读一次。检查中文、上下标、箭头端点、线旁标签和最小字号；一页装不下就拆出章图。打印版不能依靠颜色传达唯一含义。
- 任取一个入门节点和一个跨章节点，从图走到讲义或原页，核对两处都能回答节点上的自测。把“为什么放在一起”说不清的连线改成有依据的关系或移除。
- 对着图用两三句话指导起步，例如“先从列向量的线性组合走到列空间。再给右端向量换一个坐标，用图中第二条路径检验你刚才的判断。”在第一课前呈现这张图。整套交付已经获准时，接着讲第一课。
